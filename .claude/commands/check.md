description: lint, 타입 체크, 빌드를 순서대로 실행하고 결과를 요약합니다
---

프로젝트의 품질 검증을 아래 순서로 실행하세요. 테스트 러너는 없으므로 이 세 가지가 전체 검증입니다.

1. `npm run lint`
2. `npx tsc --noEmit`
3. `npm run build`

규칙:

- 앞 단계가 실패하면 다음 단계는 건너뛰고 실패 원인을 먼저 보고합니다.
- 실패 시 에러 메시지의 파일 경로와 줄 번호를 `file_path:line_number` 형식으로 인용하고, 원인과 수정안을 한국어로 설명합니다.
- 실패를 가리기 위해 eslint 규칙이나 타입을 임의로 끄지 마세요.
- 모두 통과하면 단계별 결과(통과/실패)를 한 줄씩 요약합니다.
